# Terminal Theme Color Values

Exact hex color values for 8 popular dark terminal themes, sourced from Ghostty theme configs, official theme repositories (kanagawa.nvim, nightfox.nvim, cyberdream.nvim, vim-moonfly-colors, catppuccin/ghostty), and the iTerm2-Color-Schemes collection (mbadolato/iTerm2-Color-Schemes).
