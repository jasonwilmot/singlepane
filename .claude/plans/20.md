# Ctrl+Tab Pane Focus Cycling

**Overall Progress:** `100%`

## TLDR
Ctrl+Tab cycles keyboard focus forward through all visible panes (terminal panes, explorer panes, preview). Ctrl+Shift+Tab cycles backward. Only visible panes are included. Multiple on-screen terminal panes (from Cmd+click multi-select) are each separate focusable targets, visited before explorer panes.

## Critical Decisions
- **Ctrl+Tab instead of bare Tab** — bare Tab is needed for shell tab completion in terminal; Ctrl+Tab avoids conflict
- **Local key event monitor instead of keyDown** — Ctrl+Tab is consumed by AppKit's default window/tab switching; a local monitor with `NSEvent.addLocalMonitorForEvents` intercepts it first
- **Expose terminal panes from TerminalContainerViewController** — root controller needs to enumerate individual visible terminal panes, not treat the container as one unit
- **Reuse existing focus dimming** — no new visual indicator needed; 55% opacity on unfocused panes is sufficient
