# Feature Implementation Plan — Ticket 55: Framework File Syntax Highlighting

**Overall Progress:** `100%`

## TLDR
Add syntax highlighting and bracket/tag matching for `.vue`, `.svelte`, and `.astro` files by creating a composite language pattern set (HTML + JS + CSS merged) and wiring it through the existing highlighter, bracket matcher, and file routing systems.

## Critical Decisions
- **Composite pattern set over block-aware parsing**: Merge HTML + JS + CSS patterns into a single language ID rather than parsing `<template>`/`<script>`/`<style>` block boundaries. Simpler, ships faster, good enough for regex-based highlighting.
- **Tag matching across entire file**: Enable HTML tag matching for these file types without restricting to template blocks.
- **Astro frontmatter as JS**: Treat `---` frontmatter in `.astro` as JS/TS (it is JS/TS in practice).
- **Markdown code fence support**: Map `vue`, `svelte`, `astro` tags to the composite language for rendered preview highlighting.
