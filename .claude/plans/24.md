# Markdown Document Outline Column

**Overall Progress:** `100%`

## TLDR
Add a toggleable, resizable outline column inside the content pane for markdown files. Shows styled headings (H1–H6) as clickable navigation links with scroll spy. Consolidate Edit/Save/Outline buttons into the PreviewContainerViewController tab bar area, removing per-mode toolbars.

## Critical Decisions
- **Outline owned by PreviewContainerViewController**: Single outline instance persists across preview/editor tab switches — no duplication.
- **Toolbar consolidation**: Move Edit and Save buttons from MarkdownPreviewViewController and EditorViewController into the tab bar row. Per-mode toolbars removed.
- **Edit/Save contextual**: Edit button shows in preview mode, Save button shows in editor mode. Outline toggle always visible (for markdown).
- **Resizable via NSSplitView**: Standard macOS split view with delegate for min/max widths, collapsible left pane.
- **Heading extraction from raw text**: Parse headings using same regex patterns as MarkdownSyntaxHighlighter, not from rendered HTML — works for both modes.
- **Scroll spy via scroll observation**: Editor mode observes NSTextView scroll position; Preview mode uses JavaScript IntersectionObserver + scroll listener.
- **Markdown only**: Outline toggle and column hidden entirely for non-markdown files.
- **State persistence**: Outline on/off state remembered across file switches (in-memory flag, not persisted to disk).
- **Sequential heading IDs**: HTMLConverter and outline both use sequential `heading-{N}` indices for reliable mapping.
