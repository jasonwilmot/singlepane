# Feature Implementation Plan: Feedback Button with Supabase Backend

**Overall Progress:** `80%`
**Ticket:** `.claude/tickets/63.md`

## TLDR
Add a "Feedback" button (rightmost in layout bar, theme-colored background) that opens a popover with a text field and send button. Submissions go to a Supabase `feedback` table via REST API. Spinner during submit, "Thanks!" for 1.5s then auto-dismiss, inline error on failure, 30s client-side rate limit.

## Critical Decisions
- **Supabase over email**: No SMTP credentials to manage, searchable history, trivial setup. RLS INSERT-only policy secures the table.
- **No email field**: Just feedback text + app_version. Minimum friction = more submissions.
- **Button style**: Text label "Feedback" with `chromeAccent` at 25% opacity background — adapts to user-selected theme, matches layout manager save button pattern.
- **Popover style**: Matches `LayoutManagerPopoverViewController` — same padding, stack layout, sizing approach.
- **Service pattern**: `actor FeedbackService` — follows existing `FileService` pattern. First `URLSession` usage in the codebase.
