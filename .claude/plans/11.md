# Focused Pane Tracking — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Track which panel is active across the entire app — terminal, file panes, preview. Unfocused panels dim slightly. Tab cycles focus through all visible panels. Clicking any element within a panel focuses it. First visible panel gets default focus on launch.

## Critical Decisions
- **Scope:** All panels focusable — terminal, top file pane, bottom file pane, preview — not just the dual file explorer panes
- **Focus tracking location:** `RootSplitViewController` — single event monitor, single source of truth for focus state across the whole app
- **Focus detection:** Single local event monitor hit-tests against all focusable panels — catches all clicks without modifying any child views
- **Explorer sub-panes:** The two file panes within `DualPaneExplorerViewController` are listed separately in the focusable panel list so each can be focused independently
- **Visual indicator:** Reduced opacity (`0.55`) on all unfocused panels
- **Tab key:** Cycles through all visible panels in visual order, wrapping around
- **Default focus:** First visible focusable panel on launch (typically top file pane)
- **Collapsed panels excluded:** `focusablePanels()` skips collapsed/hidden panels automatically
