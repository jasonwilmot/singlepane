# Fix: Save & Outline Button Highlight + Save Flash Feedback

**Overall Progress:** `100%`

## TLDR
The save and outline button highlights are invisible because `applyButtonHighlight` uses `bezelColor`, which doesn't work on `.accessoryBarAction` buttons. Switch to `contentTintColor` (matching the rest of the codebase) and add a brief green flash on the content panel after a successful save.

## Critical Decisions
- **`contentTintColor` over `bezelColor`**: `bezelColor` has no visible effect on `.accessoryBarAction` bezel style. `contentTintColor` is the established pattern used in 20+ places across the codebase.
- **Unhighlighted state uses `theme.chromeText`**: Instead of `nil`, use the explicit chrome text color for consistency with LayoutBarView, TerminalFindBarView, etc.
- **Save flash on `mainContentView` only**: Green overlay flash on the editor content area, not the full container (excludes tab bar strip).
- **Flash duration under 200ms**: Per project animation guidelines ("Animations serve function, never decoration. Keep them under 200ms").
- **No error feedback**: Failed saves remain silent (existing behavior).
