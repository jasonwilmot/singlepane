# Find and Replace in File Editor

**Overall Progress:** `100%`
**Ticket:** `.claude/tickets/31.md`

## TLDR
Extend the existing custom `ContentFindBarView` with a replace row (replace field + Replace / Replace All buttons) for the editor mode. Replace row is hidden by default, toggled via Cmd+Option+F or a replace icon. Replace is only available when editing — disabled in preview/code-preview/mmap modes. Replace All is a single undoable action. Syntax highlighting is re-applied after replacements.

## Critical Decisions
- **Extend custom find bar, not NSTextFinder** — The custom `ContentFindBarView` already handles search across NSTextView, WKWebView, and mmap modes. Using NSTextFinder would create two competing find bars. One system, one bar.
- **Replace row toggled, not always visible** — Triggered by Cmd+Option+F or a replace icon click. Escape collapses it back to find-only.
- **Replace only in editor mode** — Code preview is read-only, WKWebView/mmap don't support replace. Replace buttons hidden/disabled outside editor mode.
- **Single undo for Replace All** — Group all replacements in one undo group via the editor's undo manager.
