# Syntax Highlighting in Markdown Code Blocks

**Overall Progress:** `100%`

## TLDR
Apply syntax highlighting to fenced code blocks in the markdown preview. Reuse existing `CodeSyntaxHighlighter` regex patterns to wrap tokens in `<span class="syn-*">` HTML elements. CSS classes and theme colors already exist in the HTML template — just need to populate them.

## Critical Decisions
- **HTML tokenizer on CodeSyntaxHighlighter**: Add a static `highlightToHTML(code:language:)` method directly on `CodeSyntaxHighlighter` since it reuses the same patterns and color index mapping.
- **Expose `patterns(for:)`**: Change from `private static` to `nonisolated static` so the HTML method and HTMLConverter can access it outside MainActor.
- **Language tag mapper**: Add a separate `languageFromTag(_:)` method since markdown tags (`javascript`, `typescript`, `bash`, `cpp`) differ from file extensions (`js`, `ts`, `sh`, `c`).
- **Overlap behavior**: Replicate the existing last-match-wins behavior (same as NSTextStorage sequential application). No special comment-priority logic.
- **No new files**: All changes fit within the two existing files.
