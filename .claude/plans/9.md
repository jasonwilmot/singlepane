# Terminal Find Bar — Implementation Plan

**Ticket:** `.claude/tickets/9.md`
**Overall Progress:** `100%`

## TLDR
Add an always-visible find bar at the top of each terminal panel. Text field with live search, prev/next jump navigation, and a "3 of 17" match counter. Leverages SwiftTerm's built-in `findNext`/`findPrevious`/`clearSearch` API — no custom search engine needed.

## Critical Decisions
- **Omnipresent**: Find bar is always visible, not toggled with Cmd+F. It's part of the terminal chrome.
- **SwiftTerm native search**: Use `terminalView.findNext()`/`findPrevious()` for match navigation and auto-scroll. No custom buffer searching.
- **Current match only**: SwiftTerm highlights the active match via selection. No all-match highlighting for v1.
- **Per-session state**: Each `TerminalSession` owns its search text and match position so tab switching preserves state.
- **Position**: Top of terminal content area, between tab bar and terminal view — consistent with where FAYT will go in file explorer.
- **Counter via getText**: `SearchService.findAll()` is internal to SwiftTerm, so match counting uses `terminal.getText()` with string occurrence counting.
