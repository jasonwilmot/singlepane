# Custom Layout Save & Restore — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Add a "+" button to the layout bar that saves the current workspace state (column order, panel visibility, width ratios, inner split ratios) as a custom preset. Custom presets appear as numbered layout icons after a divider. Click to restore, right-click to delete. Capped at 5. Persisted via UserDefaults.

## Critical Decisions
- **Reorder via remove/re-insert**: When restoring a custom layout with a different column order, remove all `NSSplitViewItem`s and re-insert in the new order — preserves child VCs (no terminal sessions killed)
- **Presets are positional**: `SnapLayout` presets hide/show by column index, not by panel type. They don't touch column order.
- **Terminal tab orientation excluded**: Global setting only, not captured in custom layouts
- **Inner split ratios are generic**: `[PanelType: CGFloat]` map — ready for future dual-pane preview without model changes
- **No rename, no delete confirmation**: Icons are just numbered sequentially, renumber on delete
- **UserDefaults + JSONEncoder**: Consistent with ThemeManager/FontManager persistence pattern
