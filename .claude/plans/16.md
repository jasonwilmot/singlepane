# OSC 133 Shell Integration

**Overall Progress:** `100%`

## TLDR
Add OSC 133 shell integration so the embedded terminal understands command boundaries (prompt, command, output, exit code). Enables Cmd+Up/Down prompt navigation and an exit code gutter with green/red indicators.

## Critical Decisions
- **OSC interception via `parser.oscHandlers[133]`** — SwiftTerm checks user-registered handlers before built-in ones. No fork needed.
- **Main-thread safety** — `LocalProcess` dispatches PTY data to `DispatchQueue.main`, so OSC handlers and mark storage have no threading concerns.
- **Shell injection: ZDOTDIR for zsh, PROMPT_COMMAND for bash** — ZDOTDIR creates a temporary directory with a .zshrc that chains to the user's real config then sources our script. PROMPT_COMMAND prepends a bootstrap source command for bash.
- **Mark storage on `TerminalSession`** — ordered array of marks with absolute line numbers. Lightweight, co-located with existing session metadata (CWD, search state).
- **Gutter as overlay view** — thin `NSView` positioned left of the `LocalProcessTerminalView`, drawing colored dots per prompt. Avoids modifying SwiftTerm internals.
- **Prompt navigation via Cmd+Up/Down** — matches iTerm2, VS Code, Ghostty conventions. No conflict with existing keybindings.
