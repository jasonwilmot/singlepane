# Remove Grab Bars — Use Colored Border Dividers

**Overall Progress:** `100%`

## TLDR
Remove the grip overlay views (lines, arrows, background bar) from all split view dividers. Replace with a thin, always-visible colored border line. Motivation: eliminate visual artifacts when moving/resizing windows. Purely cosmetic — no layout or behavior changes.

## Critical Decisions
- **Always-visible border**: No hover effect. A colored 1px line is always drawn so panels are clearly separated in any theme.
- **4pt hit-target**: Reduced from 8pt to 4pt. Wide enough to grab comfortably, slim enough to look clean.
- **Resize cursor only**: No hover highlight animation — avoids flicker/artifact risk during fast window operations.
- **All split views**: Both `RootSplitViewController` (3-column) and `DualPaneExplorerViewController` (top/bottom file panes) get the same treatment.
- **Use existing `chromeBorder` color**: Already adapts to dark/light themes. No new theme tokens needed.
