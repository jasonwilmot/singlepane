# Feature Implementation Plan: In-App Audio Playback

**Overall Progress:** `100%`

## TLDR
Move audio playback into the app. When hook events arrive via `totalcommander://hook`, play a random MP3 from the matching voice pack folder. Voice pack selectable via dropdown next to font selector. Mute button. First pack: Sunny Singh.

## Critical Decisions
- **Folder names match event params** — `prompt/`, `notification/`, etc. so mapping is direct string lookup
- **Fire-and-forget playback** — audio clips overlap, no queue or interruption logic
- **Integration point is `AppDelegate.handleHookURL()`** — already receives all events, just needs one extra call
- **SubagentStart gets purple tab color (#A855F7)** — SessionStart and SessionEnd have no tab effects
- **settings.json already updated** — all `afplay` removed, all 6 events now route through URL scheme
