# Global Theming System — Implementation Plan

**Overall Progress:** `100%`

## TLDR
A single global theme controls every color in the app — terminal ANSI palette, terminal fg/bg, tab bar, layout bar, file explorer, markdown preview, dividers. Ship 10 presets (8 dark, 2 light) matching popular Ghostty themes. Theme switcher lives in the layout bar alongside snap layout icons. Chrome colors are auto-derived from the terminal palette to keep theme definitions compact (~22 values each). Default theme: Catppuccin Mocha.

## Critical Decisions
- **Auto-derived chrome colors** — UI chrome colors (backgrounds, borders, text, accents) are computed from the 22 Ghostty terminal color values rather than manually specified per theme. Keeps theme files small and consistent.
- **Theme switcher in layout bar** — Same row as snap layout icons, right-aligned or adjacent.
- **Catppuccin Mocha as default** — Applied on first launch, persisted in UserDefaults.
- **Hook highlights adapt to theme** — Yellow/green/red wash colors pull from the theme's ANSI palette instead of hardcoded hex.
- **Markdown preview themed** — CSS generated from active theme colors so preview matches the app.
- **Mostly dark presets, 2 light** — 8 dark (Catppuccin Mocha, Dracula, Gruvbox Dark, Nord, Tokyo Night, Solarized Dark, One Dark, Rose Pine) + 2 light (Catppuccin Latte, Solarized Light).
- **JSON theme files in bundle** — Each preset is a JSON file with the ~22 Ghostty color slots. Codable struct maps directly.
