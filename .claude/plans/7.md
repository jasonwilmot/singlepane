# Ghost Breadcrumbs Navigation — Implementation Plan

**Overall Progress:** `85%`
**Ticket:** `.claude/tickets/7.md`

## TLDR

Replace the native `NSPathControl` breadcrumb bar with a custom `NSView`-based breadcrumb component that supports ghost crumbs (faded trailing segments from previous deeper navigation), per-segment dropdown menus (sibling directories), and an edit mode with prefix-match path autocomplete.

## Critical Decisions

- **Replace NSPathControl entirely** — `NSPathControl` can't render mixed-opacity segments or per-segment dropdowns in `.standard` style. A custom view gives full control.
- **Ghost state lives in FilePanelViewModel** — keeps it per-tab automatically since each tab has its own ViewModel instance. Tab switches restore ghost state for free.
- **Dropdowns show directories only** — simpler, matches the navigation use case.
- **Prefix-match autocomplete in edit mode** — no fuzzy matching, predictable behavior.
- **Ghost crumbs: reduced opacity only** — no italic. Max 3-4 ghost segments before truncation.
- **No keyboard navigation for breadcrumb bar** — mouse/click only for now.
