# FAYT — Find As You Type in File List — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Add Directory Opus-style Find As You Type (FAYT) to the file panel. Three activation methods: search icon in breadcrumb action strip, clicking breadcrumb to enter edit mode, or just-start-typing when the file list has focus. The breadcrumb edit field is dual-purpose — path portion navigates, text after the trailing `/` filters the file list in real-time. Enter locks the filter in with a visible pill badge on the breadcrumb. Escape clears filter and restores the full list.

## Critical Decisions
- **Dual-purpose breadcrumb edit field (Option B):** Filter text lives after the trailing `/` in the existing breadcrumb edit field — no separate search bar. When path matches current directory, text after `/` is FAYT filter. When path differs, it's navigation mode with autocomplete.
- **Filter pill badge on Enter:** Pressing Enter locks the filter in, exits edit mode, and shows a dismissible pill (e.g., `[src ✕]`) after the last breadcrumb segment so the user knows why the list is narrowed.
- **Filter clears on navigation:** Navigating into a subdirectory resets the filter — new directory is a fresh context.
- **Glob support:** `*` acts as a wildcard for glob-style matching (e.g., `*.swift`). Without `*`, plain case-insensitive substring match.
- **No match counter:** Unlike the terminal find bar, FAYT does not show a match counter.
- **Just-start-typing triggers on alphanumeric keys** when file list has focus — activates breadcrumb edit mode and forwards the character.
