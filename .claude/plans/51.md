# File Context Menu — Rename, Duplicate, Delete

**Overall Progress:** `100%`
**Ticket:** `.claude/tickets/51.md`

## TLDR
Add a right-click context menu on files in the file explorer with Rename, Duplicate, and Delete. Remove the "New File" submenu from the context menu (it already lives in the breadcrumb `+` button). Standard macOS behavior: right-clicking an unselected row selects it first. Single file operations only — no multi-select.

## Critical Decisions
- **Context menu target uses `clickedRow`** — NSTableView's `clickedRow` gives us the row under the cursor, matching standard macOS right-click behavior (select-then-operate)
- **Trash, not permanent delete** — `FileManager.trashItem` for safety and undo support
- **Duplicate naming uses " copy" suffix** — Reuse the existing `availableFilename` pattern in FileService for collision handling
- **Remove "New File" from context menu** — Already accessible via breadcrumb `+` button; showing it on file right-click is confusing
