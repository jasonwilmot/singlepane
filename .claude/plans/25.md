# Custom Audio Pack Creator — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Let users create, edit, and delete their own audio packs from the voice menu. A "Create My Own" menu item opens a sheet where users name their pack and add/remove mp3/wav files to each of the 6 hook categories. Custom packs are stored in Application Support, appear in the menu with a gear icon for editing, and can be deleted from the editor sheet.

## Critical Decisions
- **Storage:** `~/Library/Application Support/Velocity/CustomVoicePacks/<pack-name>/` — files copied in, not referenced
- **Editor UI:** Sheet presented from the main window
- **Edit access:** Gear icon on each custom pack row in the voice menu
- **Empty categories:** Allowed — event is simply silent if no files present
- **File management:** Individual file removal per category in the editor
- **Delete:** Available from editor sheet only, not from the menu
