# Feature Implementation Plan: Panel Shift Arrows

**Overall Progress:** `100%`

## TLDR
Add left/right chevron arrow buttons to each panel's tab bar so users can swap panel positions at runtime. Arrows appear after existing trailing buttons, adapt to visible panel count, and persist the new column order across app restarts.

## Critical Decisions
- **Arrow placement in existing tab bars** — No new header strip. Arrows go after the rightmost existing button in each panel's tab bar row (terminal: after +/group/arrangement, explorer: top pane only after +, preview: after edit/save).
- **Icons:** `chevron.compact.left` / `chevron.compact.right` SF Symbols, `bezelStyle = .accessoryBarAction` to match existing buttons.
- **Reorder via existing `reorderColumns(to:)`** — Already handles remove-all + re-insert without destroying view controllers. No new swap mechanism needed.
- **Persistence via UserDefaults** — Simple `"savedColumnOrder"` key read at launch. Falls back to `.default` if absent. Simplest path since `LayoutConfiguration` persistence doesn't exist yet.
- **Communication via delegate/callback** — `RootSplitViewController` notifies panels of position changes so they can update arrow visibility.
