# System Notification on Stop/Notification Hook Events

**Overall Progress:** `100%`

## TLDR
Fire native macOS system notifications when `stop` or `notification` hook events arrive via the URL scheme. Clicking a notification brings the app forward and switches to the terminal tab that triggered it. Suppress when the app is already frontmost. Independent user toggle. Permission requested at first launch.

## Critical Decisions
- **UNUserNotificationCenter** (not deprecated NSUserNotification) — modern API, required for macOS 11+
- **Notification posted in AppDelegate.handleHookURL()** — alongside existing audio + visual handling, keeps all hook response logic centralized
- **Session UUID stored in notification userInfo** — enables click-through routing to the correct tab
- **Suppress when app is key** — check `NSApp.isActive` before posting; avoids noise when user is already looking at the app
- **Independent toggle from audio** — stored in UserDefaults, checked before posting
