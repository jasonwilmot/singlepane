# Claude Code Hook → Terminal Tab Highlight — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Allow Claude Code hooks to highlight terminal tabs by color via a custom URL scheme. Each terminal session injects `TC_TAB_ID` into its shell environment. Hooks fire `open -g "totalcommander://hook?tab=$TC_TAB_ID&color=22C55E"` to tint the matching tab. Wires up Stop (green), UserPromptSubmit (yellow), and Notification (red) in the user's Claude settings.

## Critical Decisions
- **Hex colors** — URL uses hex (e.g. `color=22C55E`) for future theme support. No `#` prefix to avoid URL encoding issues.
- **Background wash** — tab highlight is a subtle background color tint on the TabItemView. Transient only — no persistence across tab close.
- **`TC_TAB_ID` env var** — injected per session via SwiftTerm's `startProcess(environment:)`. Shell inherits it, so `$TC_TAB_ID` resolves dynamically in hook commands.
- **`open -g` for no focus steal** — hooks use `open -g` which opens the URL without bringing the app to front.
- **Routing chain** — AppDelegate receives URL → walks to TerminalContainerViewController → finds session by UUID → highlights tab at matching index.
