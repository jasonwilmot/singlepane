# Feature Implementation Plan: Layout Button Hotkey Assignment

**Overall Progress:** `100%`

## TLDR
Right-click layout buttons (preset and custom) to assign keyboard hotkeys. Popover-based key recorder with auto-save. Solid border = has hotkey, dotted border = no hotkey. Hotkeys fire globally within the app. Dangerous and conflicting combos are blocked.

## Critical Decisions
- **Preset icon right-click**: Opens NSPopover directly (no context menu — no need for a one-item menu)
- **Custom icon right-click**: Context menu with "Set Hotkey" + "Delete"; "Set Hotkey" opens the same popover
- **Persistence**: UserDefaults via a new `LayoutHotkeyManager` singleton (matches existing CustomLayoutManager/ThemeManager pattern)
- **SnapLayout identifiers**: Add `String` rawValue for stable persistence keys; CustomLayout already has UUID
- **Global hotkey activation**: `NSEvent.addLocalMonitorForEvents(.keyDown)` installed at WorkspaceViewController level
- **Record flow**: No confirm step — pressing a key combo auto-saves immediately
- **Hotkey visibility**: Only shown inside the popover on right-click; solid/dotted border is the only passive indicator
- **Default state**: All icons start with dotted borders (no hotkeys assigned initially)
