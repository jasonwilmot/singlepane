# Feature Implementation Plan: Terminal Tab Orientation Toggle

**Overall Progress:** `100%`

## TLDR
Add a toolbar toggle button to the terminal tab bar that lets users switch between horizontal (top) and vertical (left sidebar) tab orientation at runtime. Persists across sessions.

## Critical Decisions
- **Button placement:** In the existing trailing/bottom button chain alongside +, group, and arrangement buttons
- **Icon:** Swaps based on current state to reflect layout (e.g., `rectangle.topthird.inset.filled` for horizontal, `rectangle.leadingthird.inset.filled` for vertical)
- **Always visible:** Not gated on tab count — it's a user layout preference
- **Constraint teardown:** Store container-level constraints in an array property so they can be deactivated and rebuilt on toggle (matching the pattern `TabBarView` already uses internally)
- **Persistence:** UserDefaults save/load for `terminalTabOrientation`, matching the existing `columnOrder` pattern in `LayoutConfiguration`
