# Bracket Matching for Built-In Editor

**Overall Progress:** `100%`

## TLDR
Add bracket/brace/parenthesis matching to the code editor. When the cursor is adjacent to `{}`, `[]`, or `()`, highlight the matching pair using temporary background color attributes. Editor only, code mode only, no string/comment awareness.

## Critical Decisions
- **Editor only** — no bracket matching in read-only CodePreviewViewController
- **Code mode only** — skip when `isMarkdownMode` is true
- **Simple scanner** — no string/comment awareness; plain stack-based matching across full document text
- **Both-sides adjacency** — check character at cursor position AND character before cursor, matching VS Code/Sublime behavior
- **Temporary attributes** — use `NSLayoutManager.addTemporaryAttribute(.backgroundColor)`, same pattern as existing search highlighting
- **Unmatched = error color** — red-tinted highlight when a bracket has no match
