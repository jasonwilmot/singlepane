# Layout Manager Popover — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Replace the inline layout icon strip with a single active-layout icon (+ dropdown chevron) that opens a rich popover. The popover consolidates panel reordering (drag-and-drop), layout selection (presets + custom), inline hotkey recording/clearing, custom layout deletion, and custom layout creation into one surface.

## Critical Decisions
- **Popover, not sheet** — `NSPopover` anchored below the trigger icon. Avoids sheet drag-and-drop issues and feels like a native dropdown.
- **Single trigger icon** — All 7 preset icons + custom icons removed from the bar. Replaced by one icon showing the active layout + a ▾ chevron. Saves toolbar space.
- **Inline hotkey toggle** — No nested popover for hotkey recording. Each row has a clickable area that toggles between "Record" (capture mode) and a hotkey pill (click to clear). Reuses `LayoutHotkeyManager` validation.
- **Live panel reorder** — Panel order drag-and-drop calls `RootSplitViewController.reorderColumns(to:)` directly while popover stays open. Existing persistence path unchanged.
- **Always-selected state** — Default to first preset (`allEqual`). No "no selection" state. `LayoutBarView` tracks the active layout ID.
