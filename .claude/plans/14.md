# Feature Implementation Plan: Side-by-Side Terminal Splits

**Overall Progress:** `100%`

## TLDR
Allow users to Cmd+click terminal tabs to immediately split the terminal area into multiple simultaneous panes. Default layout is vertical (columns) with a toggle for horizontal (rows). Global find bar searches all visible panes. Single-clicking a tab collapses back to single-pane.

## Critical Decisions
- **Immediate split on Cmd+click** — no staging/confirm step; panes appear/disappear live as tabs are toggled
- **Single click ungroups** — clicking any tab without Cmd collapses to single-pane showing that tab
- **Global find bar** — searches all visible panes, navigates matches in visual layout order (left-to-right or top-to-bottom), auto-focuses pane containing current match
- **Default orientation is vertical (columns)** — toggle switches to horizontal (rows)
- **Orientation toggle only visible when 2+ tabs selected** — placed next to "+" button
- **Focus dimming reuses existing pattern** — 55% opacity on unfocused split panes
- **Drop targets pane under cursor** — not the focused pane
- **Reuse existing DividerGripView** — same divider style as main panel dividers
- **No keyboard shortcuts** for split management
