# Quick File Creation — Implementation Plan

**Overall Progress:** `88%`

## TLDR
Add a `+` button to the breadcrumb bar action strip and a right-click context menu on the file list that lets users instantly create new files from 7 predefined developer templates (.md, .txt, .json, .yaml, .swift, .py, .sh). After creation, the new file enters in-cell inline rename mode. Shell scripts auto-get executable permissions.

## Critical Decisions
- **Placement:** Trailing action strip in `BreadcrumbBarView` — per-pane, contextual, no conflict with tab `+` button
- **Inline rename:** In-cell editing (make name `NSTextField` temporarily editable + first responder) — simplest approach, no overlay
- **No keyboard shortcut:** Access via `+` button and context menu only for now
- **Escape keeps default name:** No file deletion on cancel — user gets `untitled.ext`
- **Manual refresh:** No FSEvents yet — explicitly `loadDirectory()` after creation, then find + select + edit the new row
- **Context menu infrastructure:** Right-click anywhere in file list shows menu. Only "New File >" in scope; designed for easy extension later
- **`.sh` permissions:** Auto `chmod +x` (0o755) after creation
- **Action strip is generic:** `NSStackView` container designed so FAYT search button slots in later without rework
