# File Pane Tabs — Implementation Plan

**Overall Progress:** `83%`

## TLDR
Add tab support within each file explorer pane (top and bottom) so users can open multiple directories as tabs. Reuses the existing `TabBarView` component. Each tab owns its own `FilePanelViewController` + `FilePanelViewModel` with independent directory, selection, and navigation state. Preview updates on tab switch if the tab has a selected file; new tabs leave preview as-is until a file is selected. No keyboard shortcuts in this ticket.

## Critical Decisions
- **Reuse `TabBarView` as-is** — same visual style as terminal tabs, no modifications needed
- **One `FilePanelViewController` per tab** — each tab owns its own VC + VM, swap visibility on tab switch (mirrors the terminal's `TerminalSessionManager` pattern)
- **New tab opens same directory** as the currently active tab in that pane
- **Horizontal tab bar only** for now — architecture supports both orientations but vertical is deferred
- **Tab bar above path control** — layout order: tab bar → breadcrumb → file list
- **Preview restore on tab switch is configurable** — a flag controls whether switching tabs updates the preview to that tab's `selectedFileURL`
- **No keyboard shortcuts** — Cmd+T, Cmd+W, Ctrl+Tab deferred to a separate ticket
- **Shared `FileService`** — all tabs within a `DualPaneExplorerViewController` share the same `FileService` actor instance
