# iA Writer-Style Markdown Editing Experience

**Overall Progress:** `100%`

## TLDR
Replace the line-numbered code editor for markdown files with an iA Writer-inspired stylized editing experience. Headers (`#`) are left-flush in the margin, body text is indented, list continuation and Tab/Shift+Tab nesting work automatically. Markdown and HTML keep Preview+Editor tabs; all other files get Editor only (no Preview tab).

## Critical Decisions
- **No separate gutter view for markdown**: Hide `LineNumberGutterView` entirely. Header markers live in the left margin via paragraph-level indentation (NSParagraphStyle), not a custom gutter view.
- **Paragraph indentation via syntax highlighter**: `MarkdownSyntaxHighlighter` applies `firstLineHeadIndent`/`headIndent` paragraph styles alongside colors/fonts — headers get left-flush indent, everything else gets body-level indent.
- **Different colors per heading level**: Each `#` level (H1–H6) gets a distinct color from the theme palette, applied in the existing `applyHeadings` method.
- **Auto-continue via NSTextViewDelegate**: Intercept `insertNewline:` in `EditorViewController` to parse the current line prefix and insert continuation markers.
- **Preview/Editor routing change**: `PreviewContainerViewController` conditionally hides the Preview tab for non-markdown/non-HTML files, showing Editor only.
