# Snap-to-Layout Toolbar — Implementation Plan

**Overall Progress:** `100%`

## TLDR
Add a clickable toolbar strip below the title bar with 7 layout preset icons. Each icon visually represents a column arrangement (which panels are visible/collapsed). Clicking snaps the three-column split view to that layout instantly. The active layout is highlighted and clears when the user manually drags a divider.

## Critical Decisions
- **Content-area strip, not window chrome** — toolbar is a custom NSView below the title bar, not an NSToolbar or titlebar accessory. Keeps it in the content area for full control.
- **All 3 panels always created** — currently `RootSplitViewController` skips invisible panels. Must change to always create all 3 `NSSplitViewItem`s and control visibility via `isCollapsed`. You can't collapse an item that doesn't exist.
- **Wrapper VC** — need a lightweight parent container VC that stacks layout bar + RootSplitViewController vertically, since the bar sits above the split view.
- **Layout = `Set<PanelType>`** — each preset is just a set of visible panels. Proportions are always equal among visible panels. No special width ratios.
- **Active highlight detection** — track which preset is active. Clears when user manually resizes via divider (detected via NSSplitView notifications). Re-highlights if user clicks a preset.
- **Left-aligned icons with tooltips** — icons left-aligned in the bar, tooltip on hover showing layout name (e.g. "Terminal + Explorer").
