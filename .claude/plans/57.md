# Thumbnail / Icon View Implementation Plan

**Overall Progress:** `100%`

## TLDR
Add a thumbnail grid view mode (NSCollectionView) to the file panel alongside the existing list view. Users cycle between view modes via an icon in the breadcrumb action strip. In thumbnail view, a second icon cycles thumbnail size (small/medium/large). Filenames are hidden and shown instantly on hover. View mode is per-tab and persisted. Thumbnail size is global and persisted.

## Critical Decisions
- **ViewMode enum**: Define all 5 modes (list, thumbnail, column, gallery, brief) now, only implement list + thumbnail
- **View mode**: Per-tab, persisted via UserDefaults
- **Thumbnail size**: Global, persisted via UserDefaults. Three discrete sizes (small/medium/large), cycled by clicking an icon
- **Size icon visibility**: Only appears when active tab is in thumbnail view
- **Filenames**: Hidden by default, shown instantly on hover via custom overlay (not system tooltip)
- **No inline rename**: In thumbnail view, rename is context menu only
- **Thumbnail generation**: QLThumbnailGenerator with in-memory NSCache, file-type icon fallback
- **Cycling UI**: Single view mode icon cycles list > thumbnail (> column > gallery > brief when implemented). Single size icon cycles small > medium > large.
