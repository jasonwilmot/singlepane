# Terminal Grid Layout Implementation Plan

**Overall Progress:** `100%`

## TLDR
Extend terminal split layout from 2 modes (vertical/horizontal) to 3 modes (vertical/horizontal/grid). Grid mode uses nested `NSSplitView`s to arrange terminals in a 2D grid computed via `cols = ceil(sqrt(n))`, `rows = ceil(n/cols)`. Last row stretches to fill width. Replaced Cmd+click multi-select with a simpler "group all" toggle button.

## Critical Decisions
- **Nested NSSplitView approach** — outer vertical split for rows, inner horizontal splits per row. Preserves native resize handles. Rows are independent (different column widths OK).
- **Auto-formula only** — no manual row/column override. Grid dimensions are computed automatically.
- **Group-all toggle** — single button groups/ungroups ALL tabs (replaces Cmd+click multi-select).
- **Separate arrangement button** — cycles vertical/horizontal/grid, only visible when grouped.
- **Persist via UserDefaults** — arrangement mode restored on launch.
