# Regex, Case-Sensitive, and Whole-Word Toggles in Find Bar

**Overall Progress:** `100%`
**Ticket:** `.claude/tickets/32.md`

## TLDR
Add three toggle buttons (Regex, Case Sensitive, Whole Word) to the content find bar. Toggles affect search across NSTextView (editor + code preview) and WKWebView (markdown/HTML preview). mmap search gets case-sensitive only. Invalid regex shows error state. All toggles work with find and replace.

## Critical Decisions
- **Toggle placement** — Between search field and counter label, matching VS Code's pattern
- **NSRegularExpression for all toggle-aware matching** — Unifies regex, case, and whole-word into one code path for NSTextView search
- **mmap: case-sensitive only** — Regex/whole-word disabled for mmap; rearchitecting the byte-level scanner is low value for read-only large file preview
- **WebView: full support** — Parameterize the inline JS in `searchContent` to respect all 3 toggles via JavaScript's native `RegExp`
- **Toggle state lives in ContentFindBarView** — Exposed as read-only properties; parent reads them when performing search
