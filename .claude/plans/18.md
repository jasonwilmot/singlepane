# Nerd Font Fallback Bundle

**Overall Progress:** `100%`

## TLDR
Bundle `Symbols Nerd Font Mono` in the app and register it as an automatic font cascade fallback. Icons from Starship, Powerlevel10k, eza, lazygit, etc. render correctly with any user-chosen font — zero configuration.

## Critical Decisions
- **NSFontDescriptor.cascadeList** — Core Text's built-in cascade mechanism handles glyph substitution automatically when SwiftTerm creates CTLines from attributed strings. No SwiftTerm modifications needed.
- **Always on, no toggle** — The fallback is invisible when not needed and has no performance cost. No reason to expose a setting.
- **Cascade to all views** — Terminal, code preview, and editor all get the fallback via `FontManager.makeFont(for:)`, the single font creation point.
- **Register at app launch** — `CTFontManagerRegisterFontsForURL` in AppDelegate makes the font available process-wide before any views are created.
