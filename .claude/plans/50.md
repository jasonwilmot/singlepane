# Editor Status Bar Implementation Plan

**Overall Progress:** `100%`

## TLDR
Add a status bar to the bottom of the editor panel showing cursor position, encoding, line endings, indent style, and file type. Each item (except language) is clickable with popover menus for changing values. Only visible in editor mode — hidden in preview, code preview, and media player modes.

## Critical Decisions
- **Ownership**: `PreviewContainerViewController` owns the status bar (same pattern as `ContentFindBarView`). Controls visibility on mode switch, wires data from `EditorViewController`.
- **Encoding detection**: Implement real detection by reading raw bytes — check BOM first, then heuristics. Store detected encoding on the file, not just assume UTF-8.
- **Line ending detection**: Scan file contents on load to detect LF/CRLF/CR/Mixed. Store and display.
- **Encoding menu**: Two sections — "Reopen with Encoding" (re-read from disk) and "Save with Encoding" (convert on next save). VS Code model.
- **Line ending menu**: Convert all line endings immediately on selection, mark document dirty.
- **Indent menu**: Two sections — "Indent Using Spaces/Tabs" (future input) and "Convert Indentation" (rewrite existing). VS Code model.
- **Language label**: Display only, not clickable.
- **Status bar height**: ~20px, matching the compact chrome style of the find bar.
