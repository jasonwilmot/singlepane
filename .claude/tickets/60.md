# Brief Mode (Multi-Column Filename List)

**Type:** Feature
**Priority:** Low
**Effort:** Medium

## TL;DR
Add brief mode — a Total Commander-style view that shows filenames only in multiple narrow columns, packing maximum filenames into the available space. Like a multi-column `ls` output. For users who want maximum information density.

## Current State
- Only list view with name/size/date/kind columns
- No compact filename-only display

## Expected Outcome
- Multiple narrow columns of filenames (no size, date, or kind metadata)
- Small file-type icon + filename per row
- Number of columns auto-adjusts based on panel width
- Directories visually distinct (accent color, consistent with list view)
- Keyboard navigation wraps between columns (down past last row jumps to next column)
- Hidden files at 50% opacity
- Optional: tiny file size shown on hover or as a tooltip

## Relevant Files
- `singlepane/UI/FileExplorer/FilePanelViewController.swift` — view mode switching
- `singlepane/ViewModels/FilePanelViewModel.swift` — ViewMode enum
- New: `singlepane/UI/FileExplorer/BriefModeView.swift` — multi-column layout

## Notes
- Depends on ViewMode enum infrastructure (likely from ticket #57)
- Can implement with NSCollectionView using a flow layout or custom multi-column NSTableView
- Lowest priority of the four view modes — power-user feature
- Should respect the same sort order as other views
