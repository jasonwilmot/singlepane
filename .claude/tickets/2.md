# Snap-to-Layout Toolbar

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

## TL;DR
Add a clickable toolbar strip above the three main columns with layout preset icons. Users click an icon to instantly snap panels to that arrangement — no hotkeys to memorize.

## Current State
- Three-column layout (terminal, explorer, preview) with draggable dividers
- No way to quickly collapse/expand panels or jump to a preset layout
- `NSSplitViewItem.canCollapse` is already set to `true` but unused

## Expected Outcome
- Thin toolbar bar (~28px) above `RootSplitViewController` with 7 icon buttons
- Each icon is a custom-drawn mini rectangle visualization of the layout
- Clicking snaps panels via `NSSplitViewItem.isCollapsed` + equal-width positioning
- Active layout is visually highlighted

### Layout Presets (all combinations of 3 panels visible/collapsed, minus all-hidden)

| # | Name | Visible Panels | Visual |
|---|------|---------------|--------|
| 1 | All Equal | T, E, P | `[T] [E] [P]` |
| 2 | Terminal Only | T | `[T━━━━━━]` |
| 3 | Explorer Only | E | `[━━E━━━━]` |
| 4 | Preview Only | P | `[━━━━━━P]` |
| 5 | Terminal + Explorer | T, E | `[T━] [E━]` |
| 6 | Terminal + Preview | T, P | `[T━] [━P]` |
| 7 | Explorer + Preview | E, P | `[E━] [━P]` |

## Relevant Files
- `totalcommander/UI/RootSplitViewController.swift` — apply collapse/expand + equal sizing
- `totalcommander/App/LayoutConfiguration.swift` — `PanelType` enum already defined here
- `totalcommander/App/AppDelegate.swift` — wire toolbar bar above the split view

## Implementation Notes
- Model each layout as a `Set<PanelType>` of visible panels — proportions always equal among visible
- Custom-drawn `NSView` icons (~24x16) showing filled/empty column rectangles
- Use `NSSplitViewItem.isCollapsed` for snap — already supported by NSSplitViewController
- Animate transitions with `NSAnimationContext` for polish
- Highlight the currently active layout button
- ~3 new files: `SnapLayout`, `LayoutBarView`, `LayoutIconView`
