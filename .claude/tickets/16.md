# OSC 133 Shell Integration for Embedded Terminal

**Type:** Feature
**Priority:** Normal
**Effort:** Large

## TL;DR
Add OSC 133 shell integration so the embedded terminal understands command boundaries (prompt start, command start, output start, command finished + exit code). This unlocks prompt navigation, output selection, success/failure indicators, and more.

## Current State
- Terminal supports OSC 7 (CWD reporting) via `TERM_PROGRAM=Apple_Terminal` which activates macOS's built-in `/etc/zshrc_Apple_Terminal` hook.
- Terminal supports OSC 8 (hyperlinks) via SwiftTerm's built-in handler.
- No awareness of where prompts/commands/output begin and end in the scrollback buffer.

## Desired Outcome
The terminal tracks command boundaries using OSC 133 marks and exposes them for UI features:

### OSC 133 Sequences
- `\e]133;A\a` — Prompt started
- `\e]133;B\a` — Command started (user pressed Enter)
- `\e]133;C\a` — Command output started
- `\e]133;D;{exitcode}\a` — Command finished with exit code

### Shell-Side: Integration Scripts
- Provide shell integration scripts for zsh (primary) and bash (secondary).
- **zsh**: Hook `precmd` (emit A before prompt, B after prompt draws) and `preexec` (emit C before command runs). Emit D with `$?` in `precmd` for the previous command.
- **bash**: Hook via `PROMPT_COMMAND` and `PS0` (`PS0` runs after input, before execution).
- Scripts must be defensive — don't break if user has custom `precmd`/`preexec` hooks. Append, don't replace.
- Source the scripts automatically at shell startup via env var or by injecting into the shell args.

### Terminal-Side: Mark Storage & Parsing
- Parse OSC 133 in SwiftTerm's OSC handler (or via the `LocalProcessTerminalView` delegate).
- Store marks as an ordered array of `(line: Int, type: MarkType, exitCode: Int?)` on the `TerminalSession`.
- Marks should survive scrollback — anchor to absolute line numbers, not relative positions.
- Invalidate/shift marks when scrollback is trimmed.

### UI Features (incremental)
1. **Prompt navigation** — Cmd+Up/Cmd+Down to jump between prompts (A marks).
2. **Exit code gutter indicators** — small green/red dot or icon next to each prompt based on D mark exit code.
3. **Select command output** — click/shortcut to select text between C and the next A mark.
4. **Collapsible output** (stretch) — fold long output blocks in scrollback.
5. **Rerun command** (stretch) — extract command text between B and C marks.

## Relevant Files
- `totalcommander/Terminal/TerminalSession.swift` — shell startup, env vars, CWD tracking
- `totalcommander/Terminal/TerminalContainerViewController.swift` — terminal delegate, OSC 7 handling, keyboard shortcuts
- New: shell integration scripts (e.g. `Resources/shell-integration-zsh.sh`)

## Risks / Notes
- SwiftTerm may not expose raw OSC sequences to the delegate — may need to handle via `send(source:data:)` or fork/extend SwiftTerm's OSC parser.
- Shell scripts must not interfere with the user's existing `precmd`/`preexec` functions (use `add-zsh-hook` for zsh).
- Mark positions need to update when the terminal buffer scrolls or resizes.
- VS Code, iTerm2, WezTerm, and Ghostty all implement this — plenty of reference implementations.
