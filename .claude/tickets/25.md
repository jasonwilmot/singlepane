# Custom Audio Pack Creator

**Type:** Feature
**Priority:** Normal
**Effort:** Large

---

## TL;DR

Let users create, edit, and manage their own custom audio/voice packs by importing wav/mp3 files into each hook category — directly from the voice menu.

---

## Current State

- Users can only choose from bundled voice packs and sound packs shipped with the app.
- No way to add personal audio clips or create custom sets.

## Expected Outcome

- **"Create My Own" menu item** appears in the voice/audio menu alongside existing packs.
- Clicking it opens an **editor screen** where users can:
  - See all hook categories (hello, prompt, agent, end, stop, notification).
  - Drag-and-drop or browse to add multiple `.wav` / `.mp3` files to each category.
  - Name their custom pack.
  - Save and immediately use it.
- **"Edit" option** on previously created custom packs — accessible from the menu, reopens the editor.
- Users can create **unlimited custom packs**.
- **Delete** — available from the editor screen only, not from the menu dropdown.
- Custom packs appear in the voice menu alongside bundled packs and are selectable the same way.

---

## Decisions

- **Storage:** `~/Library/Application Support/Velocity/CustomVoicePacks/<pack-name>/` — persists across app updates, standard macOS location for user-generated content.
- **Editor UI:** Sheet presented from the main window.
- **Edit access:** Small gear icon on each custom pack row in the menu — opens the editor sheet for that pack.
- **Empty categories:** Allowed. If a category has no files, that hook event is simply silent.
- **File management:** Users can remove individual files from any category in the editor.

---

## Relevant Files

- `totalcommander/Services/AudioManager.swift` — VoicePack discovery, playback, pack selection. Needs to discover custom packs from user storage in addition to bundle.
- `totalcommander/UI/LayoutBar/VoiceMenuItemView.swift` — Menu item rendering. Needs "Create My Own" and "Edit" entries for custom packs.
- **New file:** Custom pack editor view (likely AppKit window/sheet with drop zones per hook category).

---

## Implementation Notes

- `AudioManager.discoverVoicePacks()` currently only scans `Bundle.main.resourceURL/Voices/`. Must also scan the user's custom pack directory.
- `VoicePack` struct needs a `isCustom` flag or similar to distinguish user-created from bundled (controls editability/deletability).
- File imports should copy audio files into the custom pack directory (not reference originals — they may move/delete).
- Delete should remove the custom pack directory and deselect it if active (fall back to default pack).
- Menu should visually separate custom packs from bundled packs (e.g., a separator + "My Packs" header).
