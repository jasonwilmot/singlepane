# Breadcrumb Bar: Horizontal Scroll on Overflow

**Type:** Bug/Improvement
**Priority:** Normal
**Effort:** Small

## TL;DR
Deep paths get clipped/truncated in the breadcrumb bar. Wrap the segments in a horizontal scroll view so the full path is accessible, auto-scrolling to show the rightmost (current) segment.

## Current State
- Breadcrumb segments overflow and get visually clipped when the path is deep (e.g. `/Users/jasonwilmot/Documents/GitHub/cli/totalcommander/Resources/...`)
- No way to see or interact with the truncated segments

## Expected Outcome
- Breadcrumb bar scrolls horizontally when segments exceed available width
- Auto-scrolls to the rightmost segment (current directory) on navigation
- User can scroll left to see/click earlier segments
- No visible scrollbar — trackpad/mouse wheel horizontal scroll only

## Relevant Files
- `totalcommander/UI/Breadcrumb/BreadcrumbBarView.swift` — main breadcrumb container, likely needs an `NSScrollView` wrapper
- `totalcommander/UI/Breadcrumb/BreadcrumbSegmentView.swift` — individual path segments
