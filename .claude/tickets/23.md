# iA Writer-Style Markdown Editing Experience

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

---

## TL;DR

Replace line numbers with an iA Writer-inspired editing experience for markdown files. The gutter shows markdown structural symbols (header markers) instead of line numbers, and the editor auto-continues lists on Return.

---

## Current State

- `EditorViewController` uses `LineNumberGutterView` for all file types including markdown
- Line numbers are shown in the gutter regardless of file type
- No auto-continuation of lists or numbered items on Return

## Desired Outcome

**Gutter behavior for markdown files:**
- No line numbers — clean, distraction-free gutter
- When a line starts with `#`, `##`, `###`, etc., render those header symbols in the gutter (visually distinct, like iA Writer's structural markers)
- Non-header lines show an empty gutter

**Auto-continue lists on Return:**
- If the cursor is at the end of a line starting with `- `, pressing Return inserts a new line with `- `
- Same for `* ` bullet lists
- Numbered lists auto-increment: after `1. ` → next line gets `2. `, etc.
- If the user hits Return on an empty list item (just `- ` or `1. ` with no content), remove the marker and end the list
- Checkbox lists: `- [ ] ` continues as `- [ ] `

---

## Relevant Files

- `totalcommander/UI/Preview/EditorViewController.swift` — owns the text view + gutter setup; needs to conditionally swap gutter for markdown files
- `totalcommander/UI/Preview/LineNumberGutterView.swift` — current gutter; need a new `MarkdownGutterView` or a mode switch
- `totalcommander/UI/Preview/MarkdownSyntaxHighlighter.swift` — already parses headings; can share regex patterns with the gutter

---

## Implementation Notes

- Detect markdown files by extension (`.md`, `.markdown`, `.mdown`, `.mkd`) in `EditorViewController` and switch gutter mode
- For the gutter: subclass or add a mode to `LineNumberGutterView` that draws header markers (`#`–`######`) aligned to their line positions
- For auto-continue: implement `NSTextViewDelegate.textView(_:doCommandBy:)` intercepting `insertNewline:`, inspect the current line prefix, and insert the appropriate continuation
- Keep line numbers for non-markdown files — this only affects the markdown editing experience
