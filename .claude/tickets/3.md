# Claude Code Hook → Terminal Tab Highlight via URL Scheme

**Type:** Feature
**Priority:** Normal
**Effort:** Medium-Large

## TL;DR
Allow Claude Code hooks to highlight specific terminal tabs by color via a custom URL scheme. Each terminal session injects a `TC_TAB_ID` env var; hook commands use it to target the correct tab. The app registers `totalcommander://` and routes incoming events to the matching tab.

## Current State
- Terminal sessions spawn shells with default SwiftTerm env vars (`environment: nil`)
- No way for external processes to communicate with the app
- Tab highlighting is static (selected vs unselected only)

## Expected Outcome
- Each terminal shell has `TC_TAB_ID=<uuid>` in its environment
- App registers `totalcommander://` custom URL scheme
- Hook fires: `open -g "totalcommander://hook?tab=$TC_TAB_ID&event=stop&color=green"`
- App receives URL, finds tab by ID, applies color highlight
- Highlight persists until next hook event changes it

### Hook → Color Mapping (suggested defaults)

| Hook | Color | Meaning |
|------|-------|---------|
| SessionStart | blue | session opened |
| UserPromptSubmit | yellow | thinking |
| SubagentStart | purple | sub-agent spawned |
| Stop | green | done |
| SessionEnd | gray | session closed |
| Notification (permission) | orange | needs attention |

### Example Hook Config
```json
"Stop": [{
  "hooks": [
    { "type": "command", "command": "f=(/path/to/stop/*.mp3); afplay \"${f[RANDOM % ${#f[@]}]}\" &" },
    { "type": "command", "command": "open -g \"totalcommander://hook?tab=$TC_TAB_ID&event=stop&color=green\"" }
  ]
}]
```

## How It Works

1. **Env var injection** — `TerminalSession.startShell()` passes `TC_TAB_ID=<session.id>` in the environment array to SwiftTerm's `startProcess(environment:)`. Currently passes `nil`; change to default env vars + custom var.

2. **URL scheme registration** — Add `CFBundleURLTypes` to `Info.plist` with scheme `totalcommander`.

3. **URL handling** — `AppDelegate` implements `application(_:open:)`, parses query params (`tab`, `event`, `color`), routes to the correct terminal tab.

4. **Tab color highlight** — `TabItemView` gains a `highlightColor` property that tints its background. Color is persistent until changed by the next event.

## Relevant Files
- `totalcommander/Terminal/TerminalSession.swift` — inject `TC_TAB_ID` env var into `startProcess`
- `totalcommander/Info.plist` — register `totalcommander://` URL scheme
- `totalcommander/App/AppDelegate.swift` — handle incoming URL, route to tab
- `totalcommander/UI/TabBar/TabItemView.swift` — add color highlight rendering

## Risks / Notes
- `open -g` runs in background (no focus stealing) — critical for UX
- `$TC_TAB_ID` is expanded by the shell at hook execution time, so the static hook config works across all tabs
- SwiftTerm's `Terminal.getEnvironmentVariables(termName:)` returns the default env array — we append our var to it
- Need to think about routing: AppDelegate → find the right TerminalContainerViewController → find the right tab by session UUID
