# Create Product README for Single Pane

- **Type:** Feature
- **Priority:** Normal
- **Effort:** Medium

## TL;DR

Create a polished, public-facing `README.md` at the repo root that showcases **Single Pane** to GitHub visitors and potential users. Product showcase + user guide tone. Three main sections: **Terminal**, **File Explorer**, and **Reader/Editor**. Only describe what's actually built — no planned/upcoming features.

## Context

Single Pane is a native macOS app — a single pane of glass for people who want to agentically create apps without needing an IDE. Strong focus on users of Claude Code. Website: https://singlepane.dev

## Expected Outcome

A well-designed `README.md` at `/README.md` with:

### Structure

1. **Hero section**
   - App name: **Single Pane**
   - Tagline: **"A single pane of glass for Claude Code development"**
   - Brief elevator pitch: not an IDE, a focused workspace for terminal-first, AI-assisted development
   - Hero screenshot placeholder
   - Download link (leads to `.dmg` file)

2. **Terminal**
   - Tabbed terminal sessions
   - Split panes and grid view for running multiple sessions side by side
   - Drag files from the explorer into terminal to insert their paths
   - Clickable links and file paths in terminal output
   - Hints mode (Cmd+Shift+E) for quick-selecting paths/URLs from output
   - Find bar for searching terminal output
   - Exit code indicators in the gutter
   - Screenshot placeholders: terminal overview, grid view

3. **File Explorer**
   - Dual-pane browser with unlimited tabs
   - List view and thumbnail grid view
   - Smart breadcrumb navigation with autocomplete and dropdown sibling directories
   - Filter-as-you-type in any directory
   - Full-text search across filenames and file contents, with regex and case sensitivity options
   - Live directory updates — changes on disk appear instantly
   - Screenshot placeholders: file explorer overview, full-text search example

4. **Reader/Editor**
   - Markdown preview with read/edit toggle and heading outline navigation
   - Syntax highlighting for 12+ languages
   - Handles large files smoothly — only loads what's visible on screen
   - Image, PDF, audio, and video preview
   - Find and replace
   - Bracket matching
   - Encoding and line-ending info in the status bar
   - Screenshot placeholders: reader/editor, markdown outline view

5. **Layouts & Customization**
   - Three-column layout with draggable dividers
   - Snap-to-layout presets and custom saved layouts
   - Panel reordering (drag panels to rearrange)
   - 16 bundled themes (dracula, nord, tokyo-night, rose-pine, gruvbox, catppuccin, etc.)
   - Font selection
   - Screenshot placeholder: panel rearrangement / layout customization

6. **Keyboard Shortcuts**
   - Reference table of implemented shortcuts
   - Hotkey philosophy (keyboard-first, everything accessible without mouse)

7. **Download / Install**
   - Download link: placeholder pointing to `.dmg` in the repo (file not yet available — use a placeholder path like `releases/SinglePane.dmg` or a GitHub Releases link)
   - Requires **macOS 14 Sonoma** or later

8. **Footer**
   - Website link: https://singlepane.dev
   - License: **MIT** — free to use, open source, no cost

### Design Guidelines
- Product showcase + user guide tone — concise, benefit-driven, shows how to use features
- GitHub-flavored markdown
- Only describe implemented features — nothing planned/upcoming
- **Zero technical jargon** — no SwiftTerm, POSIX, actors, FTS5, FSEvents, memory-mapped, etc. Describe what users see and experience, not how it's built
- Include image placeholders for screenshots
- Screenshots go in `assets/screenshots/` at the repo root
- Use standard markdown image syntax: `![Alt text](assets/screenshots/filename.png)`
- Keep it scannable — visitors should understand what Single Pane is within 10 seconds
- Native macOS emphasis — fast, native, not Electron
- No emoji unless it genuinely helps readability
