# FAYT — Find As You Type in File List

**Type:** Feature
**Priority:** High
**Effort:** Medium-Large

## TL;DR
Add Directory Opus-style Find As You Type (FAYT) to the file panel. Three activation methods: (1) search icon button in breadcrumb action strip, (2) clicking breadcrumb to enter edit mode and typing after the trailing `/`, (3) just start typing when the pane has focus. Non-matching files are filtered out in real-time.

## Current Behavior
- Clicking the breadcrumb bar enters edit mode showing the full path (e.g., `/Users/jasonwilmot/Documents`)
- The user can edit the path and press Enter to navigate
- No inline file filtering exists
- No concept of focused/active pane — needed as a prerequisite

## Desired Behavior

### Activation (3 ways)
1. **Search icon** — click the magnifying glass button in the breadcrumb action strip (next to `+` button). Discoverable, always visible.
2. **Breadcrumb click** — enter edit mode, path shows with trailing `/` (e.g., `/Users/jasonwilmot/Documents/`). Type after the slash to filter.
3. **Just type** — when a pane has focus, start typing and FAYT activates automatically (Opus-style). Requires focused pane tracking.

### Filtering
- Non-matching files are hidden from the list in real-time (filter mode, not just highlight)
- Case-insensitive substring matching
- Pressing Enter on a single remaining result navigates into it (if folder) or selects it (if file)
- Pressing Escape exits filter mode, restores the full file list, returns to normal view
- Clearing the filter text (backspace to empty) restores the full list

### Breadcrumb integration
- If the user edits the path portion (before the trailing `/`) and presses Enter, it navigates to that directory (existing behavior preserved)
- Filter text lives after the trailing `/` — the delimiter separates path from filter

## Prerequisites
- **Focused pane tracking** — `DualPaneExplorerViewController` currently has no concept of which pane is active/focused. Need to track this so keyboard input routes to the correct pane. This is a standalone prerequisite that benefits other features too (keyboard shortcuts, status bar, etc.)

## Relevant Files
- `totalcommander/UI/Breadcrumb/BreadcrumbBarView.swift` — edit mode, path text field, action strip (search icon goes here)
- `totalcommander/UI/FileExplorer/FilePanelViewController.swift` — wires breadcrumb to file list
- `totalcommander/ViewModels/FilePanelViewModel.swift` — file list data, add filter logic here
- `totalcommander/UI/FileExplorer/DualPaneExplorerViewController.swift` — needs focused pane tracking

## Notes
- Filter should feel instant — no debounce for local file lists
- This is a Phase 1 MVP feature (in-directory filter-as-you-type per CLAUDE.md)
- Search icon in action strip follows same pattern as the `+` button (SF Symbol, `bezelStyle: .inline`, themed)
