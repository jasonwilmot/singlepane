# App State Restoration on Launch

**Type:** Feature
**Priority:** High
**Effort:** Large

## TL;DR
Remember the full workspace state when the user closes the app and restore it on next launch — terminal sessions, file explorer paths/tabs, and preview/editor selection.

## Current State
- App always launches with default state: one terminal, both explorer panes at `~/Documents`, empty preview
- All open terminals, directory navigation, and file selections are lost on quit

## Expected Outcome
On launch, the app restores:
- **Terminals:** Number of sessions, their working directories, active tab, tab orientation, arrangement mode. (Shell history/scrollback is not expected — just reopen shells at the same CWDs.)
- **File Explorer (top & bottom panes):** Each pane's open tabs, each tab's directory path, active tab index, selected file (if any)
- **Preview/Editor:** The last viewed/edited file, active mode (Preview vs Editor), outline visibility
- **Layout:** Column order, panel visibility, divider positions (some of this already persists via `LayoutConfiguration`)

## Relevant Files
- `singlepane/Terminal/TerminalSessionManager.swift` — session list, focused index, visible indices, per-session CWD
- `singlepane/UI/FileExplorer/TabbedFilePaneViewController.swift` — tab list, per-tab directory + selection, active index
- `singlepane/UI/Preview/PreviewContainerViewController.swift` — current mode, last file URL, outline visibility

## Implementation Notes
- Persist via a single `Codable` struct saved to UserDefaults or a JSON file in Application Support
- Save on `applicationWillTerminate` / `NSApplication.willTerminateNotification`
- Terminal sessions can't restore shell state — just reopen new shells at the saved CWDs
- Validate all paths still exist on restore; fall back to defaults for missing paths
- Unsaved editor changes: warn or auto-save before quit (separate concern, but related)
- Column order and tab orientation already persist — this extends to the rest of the workspace

## Risks
- Stale paths (deleted folders, ejected volumes) — must validate and degrade gracefully
- Terminal CWD detection relies on OSC 7 or `/proc` — may not always be accurate
- Large number of tabs/sessions could slow launch if restoration isn't lazy
