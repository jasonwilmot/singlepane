# Clickable URLs & File Paths in Terminal

**Type:** Feature
**Priority:** High
**Effort:** Medium-Large

## TL;DR
Make URLs and file paths in terminal output Cmd+clickable. URLs open in the default browser. File paths open a new file explorer tab navigated to the parent directory, with the file selected and shown in the preview panel.

## Current Behavior
- Terminal output is plain text — no link detection or interaction
- URLs and file paths are not visually distinguished
- OSC 8 hyperlink escape sequences are not handled

## Desired Behavior

### URL Detection & Handling
- Auto-detect `http://` and `https://` URLs in terminal output via regex
- Support OSC 8 hyperlink escape sequences (explicit terminal hyperlinks)
- Cmd+click opens URL in the user's default browser
- URLs visually underlined on hover (while Cmd is held)

### File Path Detection & Handling
- Auto-detect absolute file paths (e.g., `/Users/jason/src/app.swift`)
- Support `path:line` patterns (e.g., `/Users/jason/src/app.swift:42`) — common in compiler errors, grep output, stack traces
- Support `path:line:col` patterns
- Only highlight paths that actually exist on disk (validate before underlining)
- Cmd+click a file path:
  - Opens a **new tab** in the nearest file explorer pane, navigated to the file's parent directory
  - Selects the file in the list
  - Shows the file in the **preview panel**
- Paths visually underlined on hover (while Cmd is held)

### Visual Treatment
- No visual change by default — text looks normal
- On Cmd+hover: underline the link, change cursor to pointing hand
- Subtle color tint (theme-aware) to distinguish the underline from regular text

## Relevant Files
- `totalcommander/Terminal/TerminalContainerViewController.swift` — delegate methods, would coordinate the click action
- `totalcommander/Terminal/TerminalSession.swift` — SwiftTerm view configuration, may need mouse event handling
- `totalcommander/UI/FileExplorer/TabbedFilePaneViewController.swift` — needs API to open a new tab at a specific path and select a file

## Notes
- SwiftTerm may already parse OSC 8 sequences — investigate what's available before building custom parsing
- File path regex needs to handle spaces (common in macOS paths like `/Users/jason/My Documents/`)
- Path validation should be async/cached to avoid blocking on every mouse move
- This is a unique differentiator vs standalone terminals — clicking a path integrates with our file panes rather than just opening Finder
- Consider relative paths resolved against the terminal's CWD (available via OSC 7)
