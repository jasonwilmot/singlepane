# Markdown Document Outline Column

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

---

## TL;DR

Add a toggleable outline column to the left of the editor/preview content pane for markdown files. Shows styled headings (H1–H6) as clickable navigation links. Available in both Preview and Editor modes. Markdown files only.

---

## Current State

- No document outline or structure navigation exists
- Users must scroll manually to find sections in long markdown documents
- No way to see document structure at a glance

## Desired Outcome

- A toggleable outline column within the content pane, positioned to the left of the editor/preview
- Shows all headings (H1–H6) extracted from the document, styled with markdown formatting (colors, size hierarchy matching the editor's heading styles)
- Clicking a heading scrolls the editor/preview to that section
- Toggle on/off (button in toolbar or keyboard shortcut)
- Available in both Preview and Editor modes for markdown files
- Only appears for markdown files — not for code, JSON, HTML, etc.
- Outline updates live as the user types/edits headings

---

## Relevant Files

- `totalcommander/UI/Preview/PreviewContainerViewController.swift` — owns the content layout; needs to host the outline column alongside editor/preview
- `totalcommander/UI/Preview/EditorViewController.swift` — editor mode; outline needs to extract headings from text and scroll to them on click
- `totalcommander/UI/Preview/MarkdownSyntaxHighlighter.swift` — already parses headings; heading regex patterns can be shared with the outline

---

## Implementation Notes

- Create a new `MarkdownOutlineView` (NSView/NSTableView) that parses heading lines from the document
- Reuse heading regex patterns from `MarkdownSyntaxHighlighter` for extraction
- Style outline entries with the same per-level colors (H1=Blue, H2=Magenta, etc.) and indentation to show hierarchy
- For Editor mode: use `NSTextView.scrollRangeToVisible` to navigate to the heading's character range
- For Preview mode: use WKWebView JavaScript scroll-to-anchor
- Outline column width: fixed ~200pt, collapsible
- Live update: re-parse headings on text change notifications (debounced)
