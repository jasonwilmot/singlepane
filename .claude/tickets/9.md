# Find / Search in Terminal Windows

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

## TL;DR

Add a standard find bar to terminal windows with match highlighting, prev/next jump navigation, and a live hit counter showing current position (e.g., "3 of 17").

## Current State

Terminal windows have no built-in text search. Users cannot search scrollback buffer content without relying on shell tools like `grep` or scrolling manually.

## Expected Outcome

- **Cmd+F** opens a find bar overlay anchored to the top of the active terminal view
- As the user types, all matches in the terminal scrollback are highlighted
- Live counter displays current match / total matches (e.g., "3 of 17")
- **Enter / Down arrow** jumps to next match, **Shift+Enter / Up arrow** jumps to previous match
- Counter updates to reflect current position as user jumps
- Terminal auto-scrolls to bring the current match into view
- **Escape** dismisses the find bar and clears highlights
- Find bar does not steal focus from terminal input when dismissed — keyboard returns to terminal seamlessly

## Relevant Files

- `totalcommander/Terminal/TerminalContainerViewController.swift` — container view; find bar overlay lives here
- `totalcommander/Terminal/TerminalSession.swift` — access to scrollback buffer content for searching
- `totalcommander/Terminal/TerminalSessionManager.swift` — session coordination

## Notes

- Search should be case-insensitive by default with an optional case-sensitive toggle
- Highlight styling should respect the current theme (use a distinct highlight color that contrasts with terminal background)
- Performance: searching large scrollback buffers should be non-blocking; stream results if needed
- Consider regex support as a future enhancement (not required for initial implementation)
