# Cmd+F to Focus Search Bar in Active Pane

**Type:** Feature
**Priority:** Normal
**Effort:** Small

---

## TL;DR

Add `Cmd+F` keyboard shortcut that focuses the search/find bar of whichever pane currently has focus (terminal, file explorer, or preview/editor). Each pane type should handle it appropriately for its context.

---

## Current Behavior

- No universal `Cmd+F` shortcut to focus the search bar in the active pane
- Terminal has `TerminalFindBarView` and preview has `ContentFindBarView`, but there's no key binding to jump focus into them from the pane
- File explorer has a breadcrumb bar with filter mode but no `Cmd+F` trigger

## Expected Behavior

- **Terminal pane focused:** `Cmd+F` focuses the cursor into `TerminalFindBarView`'s search field
- **Preview/Editor pane focused:** `Cmd+F` focuses the cursor into `ContentFindBarView`'s search field
- **File explorer pane focused:** `Cmd+F` emulates clicking the search icon — opens the breadcrumb bar in search/filter mode with the current file path pre-filled and cursor positioned at the end

---

## Relevant Files

- `singlepane/UI/RootSplitViewController.swift` — routes key events based on focused pane
- `singlepane/Terminal/TerminalContainerViewController.swift` — terminal pane, owns `TerminalFindBarView`
- `singlepane/Terminal/TerminalFindBarView.swift` — terminal search bar (needs public focus method)
- `singlepane/UI/Preview/PreviewContainerViewController.swift` — preview pane, owns `ContentFindBarView`
- `singlepane/UI/Preview/ContentFindBarView.swift` — preview search bar (needs public focus method)
- `singlepane/UI/FileExplorer/FilePanelViewController.swift` — file explorer pane, owns `BreadcrumbBarView` with filter mode

---

## Implementation Notes

- Use `performKeyEquivalent(_:)` or the responder chain to intercept `Cmd+F` at each pane's view controller level
- Each find bar view should expose a `focusSearchField()` method that makes the search text field first responder
- For file explorer: call `breadcrumbBar.enterFilterMode()` with the current path string pre-filled
- Respect the responder chain — only the focused pane should respond to avoid conflicts
