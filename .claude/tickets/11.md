# Focused Pane Tracking

**Type:** Feature (Infrastructure)
**Priority:** High
**Effort:** Small

## TL;DR
Track which file pane is currently focused/active in the dual-pane layout. Unfocused pane gets slightly dimmed. Tab key toggles focus between panes. Clicking any element within a pane focuses it. Top pane (left) gets default focus on launch.

## Current Behavior
- `DualPaneExplorerViewController` has `topPane` and `bottomPane` but no concept of which is active
- Clicking in either pane doesn't update any shared state
- No visual indicator distinguishing the focused pane from the unfocused one

## Desired Behavior
- **Click to focus:** Clicking anywhere in a pane (file list, breadcrumb, empty area, any child element) marks it as the focused pane
- **Tab to toggle:** Tab key switches focus between the two panes (Total Commander convention)
- **Default focus:** Top pane gets focus on launch
- **Visual indicator:** Unfocused pane is slightly dimmed (reduced opacity) — subtle but clear
- **Focus state exposed:** `DualPaneExplorerViewController` exposes a `focusedPane` property so other features (FAYT, keyboard shortcuts, status bar) can query which pane is active

## Architecture Notes
- AppKit's responder chain already moves `firstResponder` when user clicks a table view
- Approach: when any view inside a pane becomes first responder, bubble focus up through `FilePanelVC` → `TabbedFilePaneVC` → `DualPaneExplorerVC`
- Alternatively: observe `NSWindow.firstResponder` changes and match against the two pane view hierarchies
- Opacity change on the unfocused pane's container view (e.g. `alphaValue = 0.5` or similar)

## Relevant Files
- `totalcommander/UI/FileExplorer/DualPaneExplorerViewController.swift` — owns both panes, tracks focus state, handles Tab key
- `totalcommander/UI/FileExplorer/FilePanelViewController.swift` — needs to report focus up to parent
- `totalcommander/UI/FileExplorer/TabbedFilePaneViewController.swift` — intermediary between dual pane and file panel
- `totalcommander/UI/FileExplorer/FileListTableView.swift` — primary click/keyboard target within a pane

## Notes
- Blocks FAYT (#10) keyboard activation mode
- Keep opacity dimming subtle — should feel like a hint, not disabled
- Tab key override needs to not conflict with any existing Tab behavior in the file list or breadcrumb edit field
