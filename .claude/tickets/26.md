# Bug: Save Button (and Outline Button) Highlight Not Working

**Type:** Bug
**Priority:** High
**Effort:** Small

---

## TL;DR

The save button does not visually highlight when the file has unsaved changes. The logic is wired up correctly (`hasUnsavedChanges` flag, `updateButtonVisibility()` calls), but `applyButtonHighlight` uses `bezelColor` which has no visible effect on `.accessoryBarAction` bezel style buttons. This same bug affects the outline button highlight too.

## Current State

- `hasUnsavedChanges` is set correctly when the user edits a file
- `updateButtonVisibility()` is called at all the right times
- `applyButtonHighlight()` sets `button.bezelColor = color` — **this does nothing** on `.accessoryBarAction` buttons
- Both the save button and outline button use this same broken approach
- No visual save confirmation feedback after clicking save

## Expected Outcome

1. File modified in editor → save button highlights with theme color (visible!)
2. User clicks save → brief visual feedback confirming save succeeded (e.g., flash, text change to "Saved!")
3. Save button returns to unhighlighted state
4. File modified again → save button re-highlights
5. Outline button highlight/unhighlight also works visibly

## Root Cause

All toolbar buttons are created with `.accessoryBarAction` bezel style (line 124). The `applyButtonHighlight` method (line 295) sets `bezelColor`, but `bezelColor` only has a visible effect on `.rounded` or `.regularSquare` bezel styles. For `.accessoryBarAction`, the correct approach is `contentTintColor`.

## Fix

Change `applyButtonHighlight` to use `contentTintColor` instead of `bezelColor`:

```swift
private func applyButtonHighlight(_ button: NSButton, color: NSColor?) {
    button.contentTintColor = color
}
```

This will tint the button's title text with the theme color when active, and revert to the default system color when `nil` — consistent with how `.accessoryBarAction` buttons are meant to indicate state.

Additionally, add brief visual save feedback in `saveButtonClicked()` (e.g., temporarily flash the button text/color after a successful save).

## Relevant Files

- `totalcommander/UI/Preview/PreviewContainerViewController.swift`
  - `applyButtonHighlight()` — line 295 (the fix)
  - `updateButtonVisibility()` — line 270 (calls the highlight)
  - `saveButtonClicked()` — line 705 (add save feedback here)
  - Button setup with `.accessoryBarAction` — line 124
