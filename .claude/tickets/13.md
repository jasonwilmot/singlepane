# Remove Grab Bar Overlays, Use Highlighted Borders for Panel Resize

**Type:** Improvement
**Priority:** Normal
**Effort:** Small

---

## TL;DR

Remove the visible grip overlay views (the "grab bars" with lines/arrows drawn on dividers) and replace them with subtle highlighted borders that appear on hover, so users can still drag to resize panels. This is a cosmetic-only change — no layout or resize behavior should change.

---

## Current State

- `DividerGripView` renders visual grip indicators (three horizontal/vertical lines + arrows) on top of each `NSSplitView` divider.
- `RootSplitViewController` installs these grips via `installDividerGrips()` and maintains them in `dividerGrips`.
- The grips are visually prominent and feel heavy/dated.

## Expected Outcome

- No grip overlay views rendered on dividers.
- Divider borders subtly highlight (e.g., color change or slight glow) on mouse hover to indicate they are draggable.
- Drag-to-resize behavior remains identical.
- All existing layout presets, snap behavior, and divider positions are unchanged.
- Cursor should still change to resize cursor on hover over the divider area.

---

## Relevant Files

- `totalcommander/UI/DividerSplitView.swift` — `DividerGripView` class and `installDividerGrips()` extension
- `totalcommander/UI/RootSplitViewController.swift` — grip installation and `dividerGrips` references
- `totalcommander/App/Theme.swift` — divider color token

---

## Notes

- The `DividerGripView` currently forwards mouse events to the split view — ensure hover highlight logic still allows event passthrough for dragging.
- Keep the divider hit-target size the same (or slightly larger) so resizing doesn't feel harder after removing the visual grip.
