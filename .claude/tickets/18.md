# Bundle Nerd Font Symbols as Automatic Fallback

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

## TL;DR
Bundle a symbols-only Nerd Font (e.g., `Symbols Nerd Font Mono`) inside the app so Nerd Font icons render correctly regardless of the user's chosen terminal font. Zero configuration — icons from Starship, Powerlevel10k, eza, lazygit, etc. just work out of the box.

## Current State
- Users must install a Nerd Font-patched version of their preferred font to see icons
- Without patched fonts, Nerd Font codepoints render as missing-glyph boxes (tofu)
- This is a common pain point when switching terminal apps or setting up a new machine

## Desired Outcome
- Bundle `Symbols Nerd Font Mono` (or equivalent symbols-only font) in app resources
- Register the font at app launch via `CTFontManagerRegisterFontsForURL`
- Build a font fallback cascade: user's chosen font → bundled Nerd Font symbols
- All ~9,000+ Nerd Font glyphs render correctly with any primary font
- No user configuration needed — fallback is automatic and invisible

## Relevant Files
- `totalcommander/Terminal/TerminalSession.swift` — `applyFont()` sets the terminal font
- `totalcommander/Managers/FontManager.swift` — manages active font selection
- `project.yml` — resource bundling configuration

## Notes
- The symbols-only font file is ~2MB — minimal bundle size impact
- Nerd Font symbols are licensed under MIT — safe to bundle
- Precedent: Ghostty and WezTerm both ship with built-in Nerd Font fallback
- SwiftTerm uses `NSFont` — font fallback cascade can be built via `CTFontCreateWithFontDescriptor` with a cascade list, or by subclassing/wrapping the font descriptor
- Need to verify SwiftTerm respects `NSFont` fallback cascades for glyph substitution, or if manual glyph lookup is needed
- Codepoint ranges to cover: Powerline (E0A0–E0D4), Seti-UI (E5FA–E6AC), Font Awesome (F000–F2E0), Devicons (E700–E7C5), Octicons (F400–F532), Material Design (F0001–F1AF0), Weather (E300–E3E3), Codicons (EA60–EBC5), and others
