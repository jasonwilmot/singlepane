# Column View (Miller Columns)

**Type:** Feature
**Priority:** Normal
**Effort:** Large

## TL;DR
Add Miller columns view mode — each folder opened appears as a new column to the right, showing the full hierarchy path. Like Finder's Cmd+3 column view.

## Current State
- Only list view exists
- No column/hierarchy browsing

## Expected Outcome
- Horizontal scrolling container with one NSTableView per column
- Clicking a folder adds a new column to the right showing its contents
- Selecting a file in any column shows preview in the rightmost pane (if preview module is open)
- Columns auto-scroll to keep the active column visible
- Each column independently sortable
- Back-navigation collapses rightmost columns
- Keyboard left/right arrows navigate between columns
- Hidden files at 50% opacity (consistent with other views)

## Relevant Files
- `singlepane/UI/FileExplorer/FilePanelViewController.swift` — view mode switching
- `singlepane/ViewModels/FilePanelViewModel.swift` — ViewMode enum, column navigation state
- New: `singlepane/UI/FileExplorer/ColumnBrowserView.swift` — Miller columns implementation

## Notes
- Depends on ViewMode enum infrastructure (likely from ticket #57)
- Column width should be resizable by dragging dividers
- Performance: limit rendered columns to visible + 1 buffer on each side
- Breadcrumb bar should stay in sync with the deepest selected column
