# In-App Audio Playback with Selectable Voice Packs

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

---

## TL;DR

Move audio playback from external Claude Code hooks (`afplay` via shell) into the app itself. Audio files are bundled in the app, organized by voice pack and hook event. Users can select which voice pack to use via a dropdown next to the font selector. First voice pack: `sunny-singh`.

---

## Current State

- Audio was triggered via Claude Code hooks in `~/.claude/settings.json` using `afplay`
- All `afplay` commands have been removed — hooks now only fire `totalcommander://hook` URL scheme calls
- 6 hook events with audio: `SessionStart` → hello/, `UserPromptSubmit` → prompt/, `Stop` → stop/, `SessionEnd` → end/, `SubagentStart` → agent/, `Notification` → notification/
- ~108 total MP3 files across the 6 directories, all "Sunny Singh" ElevenLabs voice
- Audio files already bundled at `totalcommander/Resources/Voices/sunny-singh/`
- No audio playback code exists in the app yet

## Expected Outcome

- Audio files bundled inside the app:
  ```
  Resources/Voices/
    sunny-singh/
      hello/          (SessionStart)
      prompt/         (UserPromptSubmit)
      stop/           (Stop)
      end/            (SessionEnd)
      agent/          (SubagentStart)
      notification/   (Notification/permission_prompt)
  ```
- App plays a random file from the matching voice/event folder when a hook event arrives
- Audio clips can overlap (fire-and-forget playback)
- Voice pack dropdown next to font selector — single value "Sunny Singh" for now
- Mute button to disable audio
- Architecture supports adding new voice packs by adding a new directory with the same event subdirectories

## Implementation Notes

- Use `AVAudioPlayer` for playback — lightweight, supports MP3
- Fire-and-forget: create a new player per event, let them overlap
- Random selection should avoid repeating the same file back-to-back
- Voice pack discovery: scan `Resources/Voices/` subdirectories
- Mute state persisted in UserDefaults
- `handleHookURL()` needs to handle new events: `hello`, `end`, `agent` (currently only handles `prompt`, `stop`, `notification`)
- SubagentStart needs purple color support added to the theme/color resolution logic

## Risks / Notes

- ~108 MP3 files increase app bundle size by ~5-15MB. Acceptable for v1.
- File naming from ElevenLabs is verbose — consider renaming to simpler names when bundling
