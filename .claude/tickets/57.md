# Thumbnail / Icon View with Resizable Thumbnails

**Type:** Feature
**Priority:** High
**Effort:** Large

## TL;DR
Add a thumbnail/icon grid view mode where files display as thumbnail previews in a grid. Include a continuous size slider (like Finder's bottom-right slider) so users can quickly scale thumbnails from small icons to large previews — critical for visually discerning between images.

## Current State
- Only list view (NSTableView) exists
- No view mode switching infrastructure
- No thumbnail generation beyond the 16x16 file icons in the list

## Expected Outcome
- NSCollectionView-based grid of file thumbnails
- Continuous slider in the status bar / toolbar to resize thumbnails (range ~48px to ~512px)
- QLThumbnailGenerator for image/document previews, file-type icon fallback for others
- Two-tier thumbnail cache: in-memory (NSCache) + on-disk (~Library/Caches/)
- Lazy generation — only visible cells request thumbnails
- Smooth resize animation as slider moves
- Directories show folder icon at all sizes
- Hidden files render at 50% opacity (consistent with list view)

## Relevant Files
- `singlepane/UI/FileExplorer/FilePanelViewController.swift` — needs view mode switching
- `singlepane/ViewModels/FilePanelViewModel.swift` — add `viewMode` property + thumbnail size state
- New: `singlepane/UI/FileExplorer/ThumbnailGridView.swift` — NSCollectionView grid implementation

## Notes
- This is the highest priority view mode — directly requested for image-heavy workflows
- Need a shared ViewMode enum that all view modes use
- Thumbnail size should persist per-tab or globally (user pref)
- Performance gate: 10K file directory must not stutter during scroll or resize
