# Zellij-Style Terminal Keybindings + Bottom Hints Bar

**Type:** Feature
**Priority:** Normal
**Effort:** Medium-Large

---

## TL;DR

Add keyboard shortcuts for terminal pane/tab management and a Zellij-inspired bottom hints bar that shows available keybindings contextually.

---

## Current State

- Terminal has **buttons** for new tab, close tab, split vertical/horizontal, group/ungroup, orientation toggle
- No keyboard shortcuts for any of these pane/tab management operations
- Only existing terminal shortcuts: `Cmd+Up/Down` (prompt nav), `Cmd+Shift+E` (hints mode)
- No discoverability surface for available keybindings

## Desired Outcome

### 1. Keyboard Shortcuts

**Core operations (map to existing buttons):**
| Shortcut | Action |
|----------|--------|
| `Cmd+T` | New tab |
| `Cmd+W` | Close tab/pane |
| `Cmd+D` | Split right (vertical) |
| `Cmd+Shift+D` | Split down (horizontal) |

**Pane navigation (new functionality):**
| Shortcut | Action |
|----------|--------|
| `Cmd+Option+Arrow` | Move focus between panes |
| `Cmd+Option+Z` | Zoom/fullscreen focused pane (toggle) |
| `Cmd+Shift+Arrow` | Resize focused pane |
| `Cmd+Option+G` | Group/ungroup all tabs |

**Tab navigation:**
| Shortcut | Action |
|----------|--------|
| `Cmd+Shift+[` / `]` | Previous/next tab |
| `Cmd+1-9` | Jump to tab by number |
| `Cmd+Shift+T` | Rename tab |

**Optional/stretch:**
| Shortcut | Action |
|----------|--------|
| `Cmd+Option+L` | Lock mode (pass all keys to shell) |
| `Cmd+Shift+C` | Copy last command output |
| `Cmd+Option+S` | Sync/broadcast input to all visible panes |

### 2. Bottom Hints Bar (Zellij-style)

A thin bar at the bottom of the terminal showing available shortcuts contextually:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ⌘T NEW TAB  ⌘D SPLIT  ⌘⌥← → NAVIGATE  ⌘⌥Z ZOOM  ⌘⇧E HINTS  ⌘F FIND     │
└──────────────────────────────────────────────────────────────────────────────┘
```

**Design requirements:**
- Non-modal (unlike Zellij) since we use direct `Cmd+` combos, not prefix keys
- **Contextual**: show pane shortcuts (navigate/resize/zoom) only when panes are split
- **Active state highlighting**: show "ZOOM" highlighted when zoomed, "LOCKED" when in lock mode
- **Scrolling tip line** below (like Zellij's green bar): rotate tips about less-obvious shortcuts
- **Dismissable**: user preference to hide once comfortable
- Uses app theme colors, monospace font

## Notes / Risks

- `Cmd+T` / `Cmd+W` may conflict with system or app-level menu shortcuts — need to handle via NSMenu or `performKeyEquivalent` override
- `Cmd+1-9` commonly used by macOS apps for tab switching, should work naturally
- Pane resize needs to integrate with existing `NSSplitView` / `NSStackView` split arrangement logic in `TerminalContainerViewController`
- Zoom (fullscreen a single pane) means temporarily hiding sibling panes and restoring on toggle — track pre-zoom layout state
- Hints bar height should be minimal (~20-24pt) to not eat terminal real estate
