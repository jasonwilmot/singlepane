# Tab Key Cycles Focus Between Visible Panes

**Type:** Feature
**Priority:** Normal
**Effort:** Medium

## TL;DR
Pressing Tab should cycle keyboard focus between visible panes (terminal, file explorer, preview) based on the current layout. Only cycle through panes that are actually on screen. If multiple terminal splits are visible, include each split as a separate focusable target.

## Current State
- No Tab-based focus cycling between panes
- Users must click to switch focus between terminal, file explorer, and preview panes
- No awareness of which panes are visible in the current layout

## Expected Outcome
- **Tab** cycles focus forward through visible panes; **Shift+Tab** cycles backward
- Pane cycle order respects the current `SnapLayout` (e.g., `terminalOnly` only has terminal targets, `terminalExplorer` has terminal + explorer, etc.)
- Hidden/collapsed panes are skipped entirely
- Multiple on-screen terminal splits each count as separate focusable targets (not terminal tabs — only terminals physically visible on screen)
- Focus ring or subtle visual indicator shows which pane is active

## Relevant Files
- `totalcommander/UI/RootSplitViewController.swift` — root layout controller, knows which panes are visible
- `totalcommander/App/SnapLayout.swift` — defines layout configurations and which panes are included
- `totalcommander/Terminal/TerminalContainerViewController.swift` — terminal view with potential splits

## Notes
- Need to intercept Tab key at the window/root level before AppKit's default tab behavior kicks in
- Must query `SnapLayout.visiblePanes` to determine cycle order
- Terminal splits need enumeration — walk the terminal container's split views to find all visible terminal views
