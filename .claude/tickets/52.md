# Ticket 52: Terminal Tab Orientation Toggle (Horizontal ↔ Vertical)

**Type:** Feature
**Priority:** Normal
**Effort:** Small

---

## TL;DR

Let users switch between horizontal and vertical terminal tabs at runtime. The underlying `TabOrientation` enum, `LayoutConfiguration.terminalTabOrientation`, and `TabBarView.orientation` already exist — just need a user-facing toggle and live relayout.

## Current State

- `TabOrientation` enum (`.horizontal` / `.vertical`) defined in `LayoutConfiguration.swift:59`
- `TerminalContainerViewController` accepts `tabOrientation` at init and sets `tabBar.orientation`
- `tabOrientation` is `let` — set once at construction, no runtime switching
- `LayoutConfiguration.terminalTabOrientation` persists the choice but there's no UI to change it
- `TabBarView.orientation` already has a `didSet { updateOrientation() }` — relayout is wired up

## Expected Outcome

- User can toggle terminal tab orientation via a toolbar button/toggle on the terminal tab bar
- Change takes effect immediately (live relayout, no restart)
- Choice persists across sessions via `LayoutConfiguration`

## Files to Touch

1. **`singlepane/Terminal/TerminalContainerViewController.swift`** — Change `tabOrientation` from `let` to `var`, add method to update orientation at runtime
2. **`singlepane/UI/TabBar/TabBarView.swift`** — Verify `updateOrientation()` handles live switching correctly (may already work)
3. **`singlepane/App/LayoutConfiguration.swift`** — Ensure `terminalTabOrientation` mutation triggers save
4. **Menu setup** (likely `AppDelegate` or wherever View menu is built) — Add menu item

## Notes

- `TabBarView.orientation` setter already calls `updateOrientation()` so the hard layout work may already be done
- Main risk: constraint conflicts during live orientation switch if existing constraints aren't fully torn down
