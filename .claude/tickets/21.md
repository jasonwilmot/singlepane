# Selected Tab Needs Thicker Border

**Type:** Improvement
**Priority:** Normal
**Effort:** Small

## TL;DR
The currently selected/active tab (both terminal tabs and file browser tabs) should have a visibly thicker border to make the selection state more obvious. Currently the selected tab only gets a subtle background tint — the border thickness is identical to unselected tabs.

## Current State
- All tabs use `thickness: CGFloat = 1` for left/right/top borders regardless of selection state
- Selected state is only indicated by a faint background color change (`chromeAccent` at 0.2 alpha)
- Hard to tell at a glance which tab is active

## Expected Outcome
- Selected tab border thickness increases (e.g., 2px) to create a clear visual distinction
- Unselected tabs remain at 1px border
- Applies to both terminal tabs and file browser tabs (both use `TabItemView`)
- Border color could also be slightly more prominent on selected (e.g., higher alpha or accent color)

## Relevant Files
- `totalcommander/UI/TabBar/TabItemView.swift:222-249` — `updateTabBorders(color:)` draws left/right/top borders with hardcoded `thickness: 1`
- `totalcommander/UI/TabBar/TabItemView.swift:197-218` — `updateAppearance()` sets background/text colors based on selection state
