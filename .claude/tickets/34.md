# Add Bracket Matching to Built-In Editor

**Type:** Feature
**Priority:** High
**Effort:** Medium

## TL;DR

Add bracket/brace/parenthesis matching with visual highlighting to the code editor. When the cursor is adjacent to a bracket character, highlight its matching pair. This is a Tier 1 (ship-blocking) feature per the built-in editor research.

## Current State

- No bracket matching exists in the editor
- No visual indication of matching `{}`, `[]`, `()` pairs
- Users editing JSON, YAML, Swift, or any nested config file have no way to visually track scope

## Expected Outcome

- When cursor is next to `{`, `}`, `[`, `]`, `(`, or `)`, the matching pair is highlighted
- Highlight both the character at cursor and its match (e.g., subtle background color or underline)
- If no match is found (unbalanced), indicate with an error color (e.g., red highlight)
- Works across the full document, not just visible lines
- Performance: matching should complete in <1ms for files under 1MB

## Relevant Files

- `singlepane/UI/Preview/EditorViewController.swift` — hook into `didChangeSelectionNotification` to trigger matching
- `singlepane/UI/Preview/CodePreviewViewController.swift` — may want matching in read-only preview too
- `singlepane/UI/Preview/CodeSyntaxHighlighter.swift` — bracket highlight colors should align with the syntax theme

## Notes

- NSTextView supports temporary attributes via `NSLayoutManager.addTemporaryAttribute(_:value:forCharacterRange:)` — use this for match highlighting so it doesn't interfere with syntax highlighting or undo
- Must skip brackets inside strings and comments (requires awareness of syntax context)
- Planned Tree-sitter migration (ticket 011) would make context-aware matching more accurate, but a basic stack-based scanner works well enough for now
