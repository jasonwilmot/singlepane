# 051: File Context Menu — Rename, Duplicate, Delete

**Type:** Feature
**Priority:** P1
**Effort:** Small
**Labels:** FileExplorer, UX
**Phase:** 1 — Foundation (MVP)

## TL;DR

The file explorer's right-click context menu only has "New File". Add Rename, Duplicate, and Delete actions for selected files. These are table-stakes file operations that every user expects on right-click.

## Current State

- Right-click context menu in `FilePanelViewController` only shows a "New File" submenu
- Rename exists via inline edit but is not discoverable from context menu
- Duplicate and Delete have no UI entry point beyond keyboard shortcuts (if any)

## Expected Outcome

- Right-click a file → context menu shows:
  - **Rename** — triggers inline rename on the selected file
  - **Duplicate** — copies the file with a " copy" suffix in the same directory
  - **Delete** — moves the file to Trash via `NSFileManager.trashItem`
- Menu items are disabled when no file is selected
- Delete should use Trash (not permanent delete) for safety
- Duplicate should handle name collisions (append number if " copy" already exists)

## Files to Modify

- `singlepane/UI/FileExplorer/FilePanelViewController.swift` — extend `menuNeedsUpdate` in the NSMenuDelegate extension, add action handlers
- `singlepane/ViewModels/FilePanelViewModel.swift` — may need duplicate/delete methods if not already present

## Risks / Notes

- Rename already works inline — just need to trigger it from the menu item
- Delete should refresh the file list after trashing (FSEvents should handle this automatically)
- Duplicate of large files could be slow — consider async with progress for files > 100MB (defer to future ticket)

## Acceptance Criteria

- [ ] Right-click context menu shows Rename, Duplicate, Delete for selected files
- [ ] Rename triggers inline rename field
- [ ] Duplicate creates a copy in the same directory with " copy" suffix
- [ ] Delete moves file to Trash (not permanent delete)
- [ ] File list refreshes after duplicate/delete
- [ ] Menu items disabled when no file is selected
